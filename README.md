# CoCログ縦書きメーカー 軽量版 GitHub ver1

ココフォリアのHTMLログを読み込み、縦書きのログ本向けに整形するためのGitHub Pages用整理版です。

## 使い方

1. `index.html` をブラウザで開く、またはGitHub Pagesに公開します。
2. ココフォリアから書き出したHTMLログを選択します。
3. 編集テキストを確認します。
4. 縦書きプレビューを見ながら設定を調整します。
5. 「印刷 / PDF保存」からPDFとして保存します。

## GitHub Pagesへの置き方

GitHubのリポジトリにこのフォルダ内のファイルをそのままアップロードし、
`Settings > Pages` から `main` ブランチの `/root` を公開してください。

## 注意

- ログはブラウザ内で処理され、サーバーへ送信しません。
- これはGitHub ver1です。今後は `docs/ARCHAEOLOGY.md` に試作版の履歴を残しながら進めます。
- 現時点ではブラウザの印刷機能を使います。PDFをサーバーで生成する機能はありません。
