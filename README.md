# ログジェネ（CoCログ縦書きメーカー） 軽量版 LOGGENE beta 2

A5安定ロールバック版です。ver19のボックステキスト実験でページ数が暴増したため、ver19の安定レイアウトをベースに戻しています。

- PDFセリフ1列の初期値: 37
- 実験的なボックステキスト分割: 無効
- 縦書きプレビュー編集: 維持
- A5基準: 維持

GitHub Pagesでは、このフォルダの中身をリポジトリ直下に上書きアップロードしてください。


## LOGGENE beta 2

地の文・セリフ内の改行をPDFカラム内部に残さず、事前に行単位へ分解して文頭欠けを防ぐ検証版。


## ver19

- ver19の1P文頭欠け修正を維持。
- 本文・セリフの英字だけ半角に戻し、縦書き内で横倒し表示されやすいように調整。
- 数字・記号・ダイスは従来通り全角寄せを維持。


## ver19
- 話者名安定実験を撤回し、本文・セリフの英数字を全角化して縦書きで統一。
- A5書き出し設定を固定プリセット化し、詳細設定を画面から非表示化。
- ver16由来の1P文頭欠け対策は維持。


## ver23

ログジェネのUI整理一式（favicon.ico / favicon PNG / apple-touch-icon）を追加しました。


## ver23

- A5固定運用に絞り、整形設定を画面から削除
- 全文縦書きプレビューを削除
- 編集テキスト中心の操作に整理
- 話者設定に「本文だけ」を追加
- 話者設定変更で編集テキストを自動リセットしない
- 元ログから再生成は確認ダイアログ付き
- 編集テキストのコピー/TXT保存/PDF用HTML保存/印刷/PDFを編集欄の近くへ移動
- PDFプレビューは重さ対策のため手動更新


## ver23
- 話者の表示名を編集テキストへ反映できるボタンを追加。
- 表示名に変更した話者名でもPC/KP/本文だけ/非表示の判定が効くように調整。
- 例：「かぐや（竹宮月子）」→「かぐや」にしても、PDF生成時にPC会話として認識されます。


## ver23

- 「本文だけ」が元ログ再生成・編集テキスト反映・PDF生成に効くように修正。
- 表示名だけでなく、話者設定そのものを編集テキストへ反映するボタンに変更。
- 非表示話者も編集テキスト反映時に削除されるよう調整。


## beta 2

話者設定の「編集テキストへ反映」が効かない問題を修正しました。

- PC / KP / 本文だけ / 非表示 を、編集テキスト内の通常話者・見出し形式・【話者】形式へ反映
- 表示名変更後も元名・表示名の両方から同じ話者として判定
- 本文だけは話者名を消し、本文だけを残す
- 非表示は該当ブロックごと削除
