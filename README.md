# CoCログ縦書きメーカー 軽量版 v70 / GitHub ver2

GitHub Pages用の緊急復旧版です。

ver1はファイル分割の骨組み寄りになり、単体HTML版で積み上げていた施策が落ちてしまったため、ver2ではいったん **最新単体HTMLを `index.html` としてそのまま載せる** 方針に戻しています。

## 使い方

1. GitHubのリポジトリに、このフォルダの中身をアップロードします。
2. `Settings > Pages` で `main / root` を公開元にします。
3. 公開URLを開きます。
4. ココフォリアHTMLログを読み込んで使います。

## 注意

- `samples/` には実ログを入れていません。公開リポジトリにシナリオ本文や卓ログを入れないためです。
- `legacy/` には今回のベースになった単体HTMLを保管しています。
- 今後ファイル分割する場合は、この `index.html` の挙動を基準にして、1機能ずつ移植してください。
