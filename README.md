# CoCログ縦書きメーカー GitHub ver12

A5安定基準版。ver10をベースに、会話罫線の接続を維持しつつ、地の文を安全に分割するための調整を追加しています。

## ver12の主な変更

- PDF セリフ1列の初期値を40文字に変更
- PDF 地の文1列の上限を追加（初期値40）
- 地の文は40文字を上限にしつつ、箇条書き・区切り線・改行が多い箇所は自動で安全側へ分割
- 地の文を改行ごとにほどいてから列化し、1つの縦書きボックス内で複数列化して文字が欠ける事故を減らす
- ver10の会話パート罫線接続を維持

## 注意

地の文40文字はまだ検証が必要です。PDF書き出し後、1P、33P、42P、51P、63P付近を重点確認してください。
