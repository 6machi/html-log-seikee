## GitHub ver1の方針

- 単体HTMLをやめ、処理をファイル分割する。
- 読み込み、正規化、レイアウト、検索を別ファイルに分ける。
- 文字が飛ばないことを優先し、CSSの `overflow:hidden` に頼りすぎない。
- テスト用のサンプルログを固定する。
- 今後、壊れたら差分で戻れるようにする。
