# 施策の地層メモ

## GitHub ver1

ファイル分割の骨組み版。構造はきれいだったが、単体HTML版で積み上げた施策が十分に移植できていなかった。
本番用ではなく、地層として残す。

## GitHub ver2

単体HTML版の機能を落とさないことを優先した移植版。
`index.html` は単体HTMLのまま。ファイル分割はまだしない。

### 引き継ぐべき施策

- v50系: ダイス結果の成功/失敗を分離しない
- v56系: 英数字の縦書き向け変換
- v59系: 同一話者の線を1本化する試み
- v60系: 読み込み時点での英数字変換
- v62系: 検索UI改善、バージョン表記
- v66以降: 本文欠け防止
- v70: 本文欠け対策を入れた確認用ベース

## 今後やるなら

1. まずver2の挙動を安定させる
2. テスト用ログで「文章が飛ばない」「読み込める」「印刷プレビューが出る」を確認
3. その後、`parser.js` / `normalize.js` / `layout.js` などに分割する


## GitHub ver3
- A5安定化を基準に、PDFセリフ1列の文字数初期値を32へ。
- 縦書きプレビュー上で本文・セリフ・ダイス枠を直接クリック編集できるようにした。
- GitHub ver2の単体HTML維持方針を継続。


## GitHub ver4

- A5安定化のため、会話文・地の文の列分割を文字数固定から実測寄りの箱組み自動分割へ変更。
- 目的：縦方向の余白を減らし、枠からはみ出す直前で自動改列する。


## GitHub ver5
- A5箱組み改良版。
- セリフ1列を39文字相当まで攻めつつ、実際の縦書きボックスに入らない場合は自動で次列へ送る処理を追加。
- 本文・セリフとも、DOM実測だけでなく視覚文字数上限も併用し、overflow hiddenで文字が消える事故を抑える。
