# ARCHAEOLOGY / 試作地層メモ

ビルの中に埋まっている石みたいな、試作の地層メモです。

## GitHub ver1

- ファイル分割の骨組み版。
- ただし、単体HTMLで積み重ねた施策が十分に移植されず、実用状態から後退した。
- 失敗した地層として残す。

## GitHub ver2

- 緊急復旧版。
- 最新単体HTML系の施策を失わないことを最優先し、`index.html` に単体HTMLをそのまま配置。
- ファイル分割よりも、まず「今までできていたことを戻す」を優先。

## 単体HTML側の主な施策

- ココフォリアHTMLログ読み込み
- 話者抽出
- PC/KP/描写の分類
- 英数字・記号の全角化
- 縦書きプレビュー
- 検索改善
- PDF/印刷用プレビュー
- A5等の用紙設定
- ダイス表示調整
- 本文欠け対策
- 同一話者の罫線調整
- 会話文の高さ調整

## 次にやるなら

いきなり全面分割せず、以下の順に1つずつ移植する。

1. `normalize.js`：全角化・記号変換
2. `parser.js`：ココフォリアHTML解析
3. `search.js`：検索UI
4. `preview.js`：通常プレビュー
5. `print.js`：PDF/印刷用プレビュー
6. `layout.js`：改ページ・罫線・ダイス表示

各段階で、同じテストログを読み込んで、文章欠け・検索・プレビュー生成を確認する。
